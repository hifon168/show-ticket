# 国内云（腾讯云 / 阿里云）上线部署手册

> 适用场景：**纯演示、不卖票收款**。主体用**企业（营业执照）**做非经营性 ICP 备案。
> 云厂商任选腾讯云或阿里云的「轻量应用服务器」，价格基本一致，本手册通用。

---

## 一、购买清单（先买后备案）

| 项目 | 建议 | 说明 |
|---|---|---|
| 域名 | 国内注册商（阿里云万网 / 腾讯云 DNSPod） | **不要用境外注册商**，无法在国内备案 |
| 服务器 | 轻量应用服务器 2 核 2G | 选**境内地域**（如上海 / 广州），系统 **Ubuntu 22.04** |
| SSL 证书 | 云厂商免费 DV 证书（1 年）或 Let's Encrypt | 微信/支付宝支付强制 HTTPS（演示也建议配） |
| 数据库 | 服务器自建 MySQL（省钱）或云 RDS（省心） | 演示用自建即可 |

> 价格提示：轻量应用服务器新人首年通常 ¥60–120，域名 ¥30–80/年，备案免费。

---

## 二、ICP 备案（强制，否则域名无法访问）

1. 在云厂商控制台完成**域名实名认证**（企业主体需营业执照、法人身份证）。
2. 提交 **ICP 备案**（选「企业」主体，非经营性），按指引上传营业执照、核验单等。
3. 管局审核 **7–20 个工作日**，期间**域名不能解析访问**。
4. 备案通过后拿到 **ICP 备案号**，挂在网站页脚。
5. **公安备案**：备案通过后 30 天内，到「全国互联网安全管理服务平台」做公安备案（1–3 天）。

> 备案期间：可用服务器**公网 IP** 直接看效果（Nginx 临时监听 IP），等备案下来再绑域名。

---

## 三、服务器初始化

把 `deploy/setup-server.sh` 上传到服务器，root 执行：

```bash
bash setup-server.sh
```

脚本会安装 Nginx / MySQL / Node18 / PM2 / Git 并开防火墙。
其中 **MySQL 安全初始化**和**建库**是交互/需改密码的步骤，按脚本内注释手动完成。

---

## 四、部署代码

```bash
cd /www/show-ticket
git clone <你的仓库地址> .
# 或本地构建后 scp 上传 web/dist 与 server/

# 安装后端依赖
cd server && npm install --production

# 构建前端（本地或服务器均可）
cd ../web && npm install && npm run build
# 构建产物在 web/dist，复制到 /www/show-ticket/web/dist
```

---

## 五、配置环境变量

```bash
cp deploy/.env.production.example server/.env
vim server/.env   # 填入 DB 密码、JWT_SECRET、CORS_ORIGIN 等
```

> `JWT_SECRET` 务必改成随机长字符串：`openssl rand -hex 32`。

---

## 六、数据库初始化

应用启动时会**自动建表（幂等）**，无需手动跑 schema。
确认 `server/.env` 的 `DB_*` 正确后，直接启动即可；如需手动初始化：

```bash
cd /www/show-ticket/server
npm run init-db
```

---

## 七、Nginx + HTTPS

1. 复制 `deploy/nginx.conf` 到 `/etc/nginx/sites-available/show-ticket`，
   把里面的 `你的域名.com` 全部替换为真实域名。
2. 启用站点并删除默认页：

```bash
ln -s /etc/nginx/sites-available/show-ticket /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
```

3. 申请免费证书（二选一）：
   - **云厂商控制台**申请免费 DV 证书，下载 Nginx 版，放到
     `/etc/nginx/ssl/你的域名.com/`（含 `fullchain.pem` 与 `privkey.pem`）。
   - 或 `certbot --nginx -d 你的域名.com -d www.你的域名.com`（Let's Encrypt）。
4. 校验并重载：

```bash
nginx -t && systemctl reload nginx
```

---

## 八、启动与守护（PM2）

```bash
cd /www/show-ticket/server
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup   # 按提示设置开机自启
```

`ecosystem.config.js` 中 `cwd` 指向 `/www/show-ticket/server`，PM2 会读取该目录下的 `.env`。

## 九、验证与日常运维

```bash
# 接口健康检查
curl -k https://localhost/api/health   # 或你实际的健康检查路由
```

## 十、与 Railway 部署的差异小结

| 项目 | Railway（之前） | 国内云（现在） |
|---|---|---|
| 域名 / TLS | 平台托管 | 自配 Nginx + 免费证书 |
| 进程守护 | 平台托管 | PM2 |
| 数据库 | Railway MySQL 插件 | 自建 MySQL / 云 RDS |
| 合规 | 境外免备案 | 必须 ICP 备案 + 公安备案 |
| 配置变量 | `MYSQLHOST` 等 | `DB_*`（`config` 已兼容，无需改代码） |

代码本身**无需改动**，只需提供正确的 `server/.env` 与 Nginx 反代即可。

## 已知限制（演示阶段）

- 不接入真实支付（演示模式），如需收款需改用企业主体 + ICP 经营许可证 + 微信/支付宝商户号。
- 每城同步场次约 50 场（受内存限制），如需收录更多可提升服务器配置并调大 `SYNC_PAGE_SIZE`。

## 十一、备案合规要点（重要，避坑）

> 适用：走境内服务器 + ICP 备案的场景。核心原则——**网站不能表现为"经营性售票"，且展示业务不能明显超出营业执照经营范围**。

### 规则要点
- 非经营性备案**不要求**执照包含"互联网信息服务"条目，普通企业官网展示自有业务即可。
- 但审核遵循"三一致"：**备案主体、域名实名、网站实际内容**要匹配；网站展示的业务不能明显超出营业执照经营范围。
- 北京管局审核偏严。企业网站名称需与主体匹配，**避免"票务、平台、资讯"等易超范围或需前置审批的词汇**；服务内容填"单位门户网站"或"其他"最稳。
- 一旦网站表现为"在线售票/票务平台"（有购票按钮、票价、支付入口），审核员会比对经营范围；若执照不含票务，可能被驳回或要求补 **ICP 经营许可证**（经营性，需执照增项"第二类增值电信业务"，周期 1–3 月）。

### 本项目的实操建议（以"北京磐石引擎科技有限公司"为例）
- 公司执照经营范围**不含卖票/票务**，因此备案时**不要**把网站定位成"售票平台"。
- 演示本就不收款，建议**隐藏或禁用购票/支付入口**（改成"敬请期待"之类），让网站表现为"演出资讯展示"。
- 备案填报：
  - 网站名称用中性：如「磐石引擎演出资讯」或「北京磐石引擎官网」，**切勿**用"XX票务网/售票平台"。
  - 服务内容选：**单位门户网站** 或 **其他**。
  - 网站简介写：「非经营性演出资讯信息展示，提供演出排期介绍」。
- 这样业务不超范围、非经营，基本可一次过。

### 如确实要保留"售票平台"面貌
需先变更营业执照增项（如"票务代理/第二类增值电信业务"）或办理 ICP 经营许可证，成本高、周期长，**演示阶段不推荐**。

---

## 十二、免备案方案：香港 / 海外服务器（最省心）

> 想最快上线看效果、不想折腾备案 → 选这个。

- **腾讯云香港轻量 / 阿里云香港轻量**，或继续用 Railway（境外）：服务器在中国香港/海外，**强制 ICP 备案不适用**。
- 仅需（视情况）做**公安联网备案**（全国互联网安全管理服务平台），通常宽松。
- 国内访问比境内略慢，但演示足够；**代码零改动**，照搬本手册第七~九章（Nginx/PM2/运维）即可，跳过第二~六章（备案）。
- 注意：微信/支付宝商户接入对境外服务器有限制，但演示不收款无影响。

### 方案对比速查

| 方案 | 是否需要 ICP 备案 | 适合场景 | 风险/成本 |
|---|---|---|---|
| A 企业备案+去售票化 | 是（免费，7–20天） | 长期境内合规运营 | 需隐藏购票入口，填报中性 |
| B 保留售票面貌 | 是 + 需ICP经营许可证 | 真卖票经营 | 高（执照增项/办证 1–3月） |
| C 香港/海外服务器 | 否（仅公安备案） | 演示/快速看效果 | 国内访问略慢，零备案烦恼 |
